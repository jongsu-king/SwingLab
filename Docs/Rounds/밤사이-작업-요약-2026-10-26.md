## 실시간 런치모니터 (요청하신 것) 🟡 실험 단계

- **잴 수 있는 것:** 볼 스피드와 발사각. 240fps 영상에서 공 지름(42.67mm)을 자로 써서 측정해요.
- **캐리:** 측정값이 아니라 공개 스핀 범위로 시뮬레이션한 **범위**로만 보여줘요.
- **측정 불가로 표시:** 스핀, 클럽 스피드
- **합성 영상 테스트:** 오차 0.1% 이내. **실제 영상에서는 아직 검증 전**이에요.
- **새 기능 2개:**
  1. **촬영 화면 → "발사 측정 모드"** 켜기: 240fps에 셔터 1/2000초로 고정해요. 어두우면 경고해요.
  2. **스윙 상세 → "발사 측정 (실험적)"**: 영상에서 공을 한 번 탭하면 볼 스피드와 발사각을 보여줘요.
- 아직 "실험적 기능"으로 표시돼요. TrackMan과 비교해서 ±3% 이내가 확인돼야 정식 기능이 돼요.

## "인터넷 자료로 학습"

인터넷 스윙 영상으로 볼 스피드를 "예측"하는 학습은 하지 않았어요. 저작권 문제가 있고 정답 데이터가 없어서 결국 지어낸 숫자가 되기 때문이에요. 대신 **USGA 연구, TrackMan 투어 평균** 같은 공개 통계를 출처와 함께 넣어서 클럽별 **참고 범위**로 보여줘요. 항상 "참고: 공개 평균"으로 표시해서 본인 측정값과 구분해요.

## 내일 해주시면 좋은 것

1. **iPhone을 Mac에 USB로 연결**, Xcode → 설정 → Accounts에서 Apple ID 로그인, iPhone 개발자 모드 켜기 → 제가 실제 폰에 설치할게요
2. 설치 후 **앱에서 "발사 측정 모드"를 켜고** 정면에서 공을 쳐서 10샷 정도 찍기. 밝은 곳에서, 박수 한 번 치고 시작해 주세요.
3. 가능하면 **TrackMan 옆에서** 찍고 샷마다 TrackMan 화면 사진도 찍어 주세요 → 정확도 합격 판정용이에요
