# 작업 요약 (11월 8일)

요청: 인스타그램 릴([wadelambert_, ShotVision 테스트 영상](https://www.instagram.com/reel/DdRwZ5LouIl/))에 나온 아이폰 런치모니터 기능을 SwingLab에 전부 넣기.

영상에서 확인한 ShotVision 화면은 이랬어요.

1. 폰을 거치대에 두고 공을 비추면 **카메라-공 거리**를 재서 "0.88 m · TOO FAR", "0.71 m"처럼 알려줘요.
2. 샷 화면에는 **Carry, Total, Ball speed, Club speed, Back spin, Launch angle** 6개 타일이 있고, 가상 레인지 배경 위에 궤적이 그려져요.
3. 상단에 **Auto Club**, 우측에 **1 CLUB · 2 SHOTS** 같은 세션 카운트, **123**(숫자만 보기), **L/R**, 스피커(음성) 버튼이 있어요.
4. 샷을 치면 폰을 만지지 않아도 값이 갱신되고, 샷 직후 작은 **리플레이** 창이 떠요.

## SwingLab에 넣은 것

전부 "모르는 숫자는 지어내지 않는다"는 원칙 안에서 만들었어요. 측정값은 여전히 볼 스피드와 발사각뿐이고, 나머지 타일은 출처 배지가 뭔지 말해줘요.

| ShotVision 기능 | SwingLab 구현 | 출처 표시 |
|---|---|---|
| 6개 타일 | `LaunchReadoutBuilder`가 샷 하나로 6개 타일을 만들어요. 실시간 패널, 영상 측정 화면, 런치 기록(클럽별 평균)에서 같은 그리드를 써요. | 볼 스피드·발사각: 비전 분석값 |
| Carry | 공개 스핀 범위로 비행 시뮬레이션 5회 → 최단~최장 범위 | 시뮬레이션 |
| Total | 캐리 + 바운스·롤 모델(`BallRoll`, 페어웨이 가정) → 범위 | 시뮬레이션 |
| Club speed | 볼 스피드 ÷ 해당 클럽의 공개 스매시 팩터 범위 | 추정값 |
| Back spin | 캐리를 시뮬레이션할 때 쓰는 공개 스핀 범위 그대로 | **참고 — 발표된 평균값** (새 출처 종류) |
| 카메라 거리 안내 | 공을 탭하면 어드레스 프레임 4장으로 공 크기를 재고, 렌즈 화각으로 거리를 계산해 **너무 가까움 / 준비 완료 / 너무 멂**을 보여줘요 (`LaunchSetupChecker`). | 비전 분석값 |
| Auto Club | 공개 발사 평균표에서 (볼 스피드, 발사각)이 가장 가까운 클럽을 골라요. 틀리면 메뉴에서 바꿀 수 있고, 어떤 클럽을 왜 골랐는지 적어 줘요. | 추정값 |
| 세션 카운트 | 패널 위에 "클럽 1개 · 3샷" 알약 | — |
| 가상 레인지 + 궤적 | `LaunchRangeView`: 개념도(축척 아님). 점선 궤적, 바닥에 캐리·토탈 범위 띠 | 시뮬레이션 |
| 리플레이 | 임팩트 직후 6프레임을 겹친 **스트로브** 이미지에 추적한 공 위치를 표시 (`LaunchStrobe`). 영상 클립 저장은 아직 아니에요. | 비전 분석값 |
| L/R | 공을 다시 탭하지 않고 비행 방향만 뒤집는 버튼 | — |
| 123 | 숫자만 보기 ↔ 레인지 그림 전환 (설정이 저장돼요) | — |
| 음성 | 샷마다 볼 스피드·발사각·캐리 범위를 앱 언어로 읽어 줘요 (`LaunchSpeaker`). 스핀·클럽 스피드는 읽지 않아요. 패널의 스피커 버튼과 설정 → 코칭 → 음성 읽기로 끌 수 있어요. | — |
| 폰을 만지지 않는 연속 측정 | 이미 그렇게 동작했고, 샷마다 공 크기를 다시 재요. | — |
| 세션 요약 (Track) | 패널의 "세션" 펼침: 클럽별 샷 수, 평균 볼 스피드·발사각(2샷부터), 표준편차(5샷부터), 시뮬레이션 캐리 범위. 샷마다 **같은 클럽의 직전 샷 대비 변화**(볼 스피드·발사각)를 보여줘요 (`LaunchSession`). | 비전 분석값 / 시뮬레이션 |
| 미스샷 지우기 | **마지막 샷 취소** 버튼: 세션 요약과 런치 기록에서 함께 지워요. | — |
| 거리 권장 범위 | 판정이 "준비 완료"가 아닐 때 "공에서 약 2.1 m~4.6 m 떨어진 곳에 두세요"처럼 카메라를 둘 수 있는 범위를 알려줘요. | 비전 분석값 |

넣지 않은 것: 가로 화면 레이아웃(앱 전체가 세로 전용), ShotVision 웹사이트에만 있는 QuickShot·드릴·가상 골프.

- **새 문서** `Docs/Principles/LaunchReadout.ko.md` (영어판 `LaunchReadout.md`): 6개 타일·세팅 안내·자동 클럽·스트로브·세션·음성이 어떻게 계산되는지 수식, 코드 상수, 예시 숫자, 한계까지 전부 적었어요.

- README(한·영): 기능 목록, 출처 표, 다이어그램, 테스트 수.

## 실기기에서 확인해 주시면 좋은 것

1. 런치 모드 → 실시간 측정 → 공 탭 → 거리 판정이 상식에 맞는지(약 3 m에서 "준비 완료").
2. 샷 후 6개 타일과 스트로브가 뜨고 음성이 나오는지, 자동 클럽이 그럴듯한지. 두 번째 샷부터 "직전 샷 대비 변화"와 세션 요약이 맞는지, "마지막 샷 취소"가 런치 기록에서도 지우는지.
3. 패널이 작은 폰에서 컨트롤을 가리지 않고 스크롤되는지.
