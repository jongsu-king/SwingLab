## 3. Task C — "learn from the internet", honestly

The user asked SwingLab to learn from internet material so that it can show typical values by distance, club, impact, ball speed, and so on.

**Not allowed:** training a model on scraped swing videos to *predict* ball speed or carry from body motion. That conflicts with v6.0 §2 and copyright/ToS, and there is no ground truth.

Instead, build a cited **reference dataset** of published statistics and use it only as clearly labelled context:

- **Sources to research and cite (verify each number):**
  - USGA *R22-01 Launch conditions of male and female golfers of different skill levels*
  - USGA *DI Golfer Performance Measurement (2023 update)*
  - TrackMan PGA/LPGA Tour averages (older table and the May 2024 update)
  - Any other primary source you can verify.
- **Core:** `ReferenceLaunchData`. For each club category, skill band, or club speed band: club speed, ball speed, smash factor, launch, spin, carry, and apex as published, with the source and year for each value. It contains no derived claims beyond simple interpolation, which must be labelled.
- **Uses, all labelled "Reference — published averages" and never as the user's own measurement:**
  1. **Spin range assumptions** for the launch monitor's carry range (replace any hard-coded guesses).
  2. A **Club profile** view in My Bag: for each club, the user's own recorded values beside the reference band for a golfer of similar measured ball speed, when one exists.
  3. **Gapping hints** from reference smash and launch, phrased as context, not advice.
- **Tests:** source/value integrity (units, ranges, every value cited) and the interpolation math.
