# SwingLab support notes

This is a development build. A public support URL and the publisher's support contact must be established before distribution.

- If a video has no reliable pose, use one golfer, good lighting, and a steady full-body view; try a shorter clip. No ball or club detector is included.
- If phase estimates are wrong, seek to the correct frame, select the phase, and set the marker. Clear conflicting markers first. Impact remains an estimate unless manually placed; it is not radar detection.
- If course distance is missing, request GPS or place a ball position and target manually. Shot logs require a recent usable GPS fix, even when the planning origin is manual.
- If landing regions are missing, enter positive carry and lateral standard deviations plus a carry average in My Bag. These are conditional statistical estimates from your inputs.
- If camera access is denied, change camera permission in iPhone Settings or import a video. Simulator cameras do not establish real camera capability.
- Local records can be edited in their feature screens or deleted in Settings. Export original videos before deletion if you need an independent copy. No recovery or cloud synchronization service is included.

For an engineering bug report, include iPhone/iOS version, the screen, steps to reproduce, and whether you used recorded or imported footage. Avoid sharing identifiable video or precise GPS coordinates unless you choose to do so.
